Welkom in REA Legacy SMP

Bouw jouw legacy in REA Legacy SMP Alles wat je hoeft te doen is en moddable louncer instaleren en onze modpack op je client te zetten

modpack status: Unknown

Hoe zet ik mijn louncer op

  1. download de mods zip hierboven die moet je hebben om de server te kunnen starten
  2. instaleer en louncer dat mods suport als je die nog niet hebt bijvoorbeeld: Modrinth of Curse forge
  3. maak en nieuw profiel aan ik gebruik Modrinth als voorbeeld
  4. select custom setup
  5. nu moet je de instance en naam gecen, selecteer fabric als loader en zorg ervoor dat je de goede version instelt wat je op de landings pagina kunt (?)
  6. Bij de 3 puntjes moet je Open folder selecteren zodat we in de bestanden van de instance komen
  7. Open de mods folder hierin moet je de inhoud van de zip dat je boven kunt downloaden plaatsen
  8. Je kunt zelf nog wat client only mods toevoegen als je dat wilt
  9. Start minecraft via de modable louncer zodat het je mods laad
  10. wacht voor de "press enter to enable narator" jumpscare
  11. ga naar multiplayer en dan Add Server
  12. geef de server en naam en voor de server adress kun je en admin vraagen klik Done en je kunt gaan beginnen met het bouwen van je legacy
